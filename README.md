Customer Behaviour Analysis

An end-to-end customer behaviour analysis project using Python, Pandas, NumPy, and Power BI. The project focuses on understanding sales performance, customer behaviour, churn patterns, product performance, and return trends through interactive dashboards.

🛠️ Tools & Technologies

- Python
- Pandas – Data cleaning and transformation
- NumPy – Data manipulation and calculations
- Power BI – Data visualization and interactive dashboard development

🔄 Data Preparation

The original customer behaviour dataset was processed using Python.

- Loaded and explored the raw dataset using Pandas.
- Cleaned and prepared the data using Pandas and NumPy.
- Separated the original dataset into two analytical tables:
  - Customer Information
  - Transactions
- Prepared the cleaned datasets for analysis and visualization in Power BI.

📊 Dashboard 1 — Sales Overview

The Sales Overview dashboard provides a high-level view of sales and customer performance.

Visualizations

- Sales by Product Category — Bar Chart
- Sales by Age Category — Column Chart
- Sales by Period — Line Chart
- Sales by Gender — Pie Chart
- Sales by Payment Method — Donut Chart
- Average Order Value — Gauge
- Time Slicer for interactive filtering

Key Metrics

- Total Sales
- Total Customers
- Total Orders
- Total Returns
- Return Rate

🎯 Project Objective

The objective of this project is to demonstrate an end-to-end data analytics workflow, from raw data preparation using Python to interactive business intelligence dashboards using Power BI.

The project showcases practical skills in data cleaning, data transformation, exploratory analysis, KPI development, data visualization, and business-oriented analysis.
